# 平衡代理仿真报告

- 对局：Boom、Boom+Rocky、Sharkk、Core-00连续战斗代理模型。
- 玩家策略：近战突进、中距消耗、远程风筝、护盾消耗、治疗拖延、爆发、随机合法、移动规避。
- 三轮：500、2,000、10,000局/组合；最终锁定权重不读取隐藏武器信息。
- 目标：未强化时敌方胜率50%–60%；强化后敌方胜率27%–33%。

`balance_runner.tscn`会以固定评估种子复算最终代理样本。该结果用于数值回归，不承诺真实玩家胜率；正式发行仍应收集真人遥测复核。

本次复测：640,000个代理样本；未强化敌方胜率55.24%，强化后敌方胜率30.03%，两项均在目标区间。
